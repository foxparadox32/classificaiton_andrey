# Классификация тональности отзывов IMDB

Бинарная классификация отзывов о фильмах (positive / negative): от бейзлайна на «мешке слов» до дообучения трансформера.
Решение построено по [шаблону](https://github.com/EliseevVadim/hallucinations-detection): EDA, бейзлайн и нейросети в отдельных ноутбуках, общий код — в пакете `core/` (адаптированные модули шаблона).

## Данные

[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews) (Kaggle): 50 000 отзывов, колонки `review` и `sentiment`.
Файл `IMDB Dataset.csv` в репозиторий не входит: скачайте его с Kaggle и положите в корень проекта.

После очистки (удаление `<br />`, 418 дубликатов и отзывов короче 10 слов) осталось **49 577** текстов, классы сбалансированы (≈50/50).
Разбиение: train / test = 80 / 20, стратифицированное, одинаковое во всех ноутбуках (`core/data.py`). Валидация для подбора гиперпараметров и ранней остановки выделяется из train.

## Структура

| Файл | Содержание |
|---|---|
| `eda.ipynb` | Загрузка, очистка, баланс классов, длины текстов, стоп-слова, облака слов, информативные n-граммы |
| `baseline.ipynb` | Count / TF-IDF / Hashing + LogReg, сравнение классификаторов (NB, RandomForest, LightGBM), отбор токенов (стоп-слова, n-граммы, χ²) |
| `neural_networks.ipynb` | NN с нуля (FastText-like, TextCNN, BiLSTM), GloVe, предобученные модели (MiniLM, DistilBERT), итоговое сравнение, анализ ошибок, выводы |
| `core/` | `data` — загрузка и разбиение; `nlp` — токенизация и анализ n-грамм; `vectorization` — `SequenceVectorizer`, `BertVectorizer`; `nn_models`, `nn_training` — модели и обучение с ранней остановкой; `baseline_training`, `training_results` — метрики и реестр результатов; `visualization` — графики; `utils` |
| `results.csv` | Итоговые метрики всех 19 моделей на тесте (генерируется `neural_networks.ipynb`) |
| `results/` | Промежуточные результаты `baseline.ipynb`, которые использует `neural_networks.ipynb` |

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook
```

Ноутбуки запускаются по порядку: `eda.ipynb` → `baseline.ipynb` → `neural_networks.ipynb` (третий читает результаты второго из `results/`).
Время на RTX 4070 Laptop: EDA ~1 мин, бейзлайн ~5 мин, нейросети ~30 мин. Пиковое потребление оперативной памяти — до ~2.2 ГБ в первых двух ноутбуках и ~4.4 ГБ в третьем. GloVe и модели HuggingFace скачиваются автоматически.

## Результаты (тест, 9 916 отзывов)

| Группа | Лучшая модель | F1 (macro) | ROC-AUC | Время обучения |
|---|---|---|---|---|
| 1. Бейзлайн | TF-IDF + LogReg | 0.896 | 0.961 | 8 с |
| 2. Отбор токенов | TF-IDF 1-2-граммы + χ² (k≈227 тыс.) + LogReg C=10 | **0.918** | 0.973 | 26 с |
| 3. NN с нуля | FastText-like | 0.904 | 0.963 | 14 с |
| 4. Готовые эмбеддинги | GloVe + BiLSTM | 0.907 | 0.968 | 233 с |
| 5. Предобученные | DistilBERT fine-tuning | 0.909 | **0.975** | 540 с |

## Выводы

- Задача хорошо решается «мешком слов»: TF-IDF + LogReg уже дают F1 ≈ 0.90. Среди классических алгоритмов линейная модель лучше LightGBM, наивного Байеса и случайного леса.
- Отбор токенов (биграммы, sublinear TF, χ² + подбор регуляризации) даёт +2 п.п. Удаление стоп-слов вредит, так как выкидывает отрицания.
- TextCNN и BiLSTM с нуля сходятся медленно (12–15 эпох) и уступают линейной модели. Инициализация GloVe даёт им +0.6–1.4 п.п. F1 и ускоряет сходимость в 3–4 раза.
- DistilBERT — лучший по ROC-AUC, но по F1 при пороге 0.5 уступает TF-IDF + χ² и учится в ~20 раз дольше. Его ошибки мало пересекаются с ошибками моделей «мешка слов», поэтому ансамбль — перспективное улучшение.
